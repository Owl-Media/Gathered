# Your Dashboard

Your dashboard is the first thing you see after signing in. It lists every event you have created — and nothing else. Other organisers' events are not visible to you, and yours are not visible to them.

![The Gathered organiser dashboard, listing one event with counts for invited, yes, no and waiting, and buttons to manage, view guests, export or open the public page.](/images/getting-started/dashboard.png)

## Before you have any events

A new account shows a single card:

> **No events yet.** Set up your event details, add your guest list, and share a private invitation link with each guest.

with a **Create your first event** button. See [Create Your First Event](/getting-started/create-your-first-event).

## Event cards

Once you have events, each one appears as a card showing:

- The **event name**, which opens the event.
- The **event date**.
- **RSVP by** — the deadline, shown in the event's own timezone.
- A **Closed** badge, if the deadline has already passed.

### The four counts

| Count | Meaning |
| --- | --- |
| **Invited** | Everyone currently on your guest list |
| **Yes** | Guests who have accepted |
| **No** | Guests who have declined |
| **Waiting** | Guests who have not replied yet |

Guests you have removed are not counted in any of them.

The counts include replies you entered yourself on the [Responses](/events/responses) tab, not just ones guests submitted. Whether a reply came from the guest or from you is recorded per guest and shown on that tab.

### Quick actions

Four buttons on every card:

- **Manage** — opens the event's [Details](/events/details) tab.
- **Guests** — jumps straight to the [guest list](/events/guests).
- **Export** — jumps straight to [Exports](/events/exports).
- **View page** — opens the [public event page](/invitations/public-event-page) in a new tab, exactly as a guest would see it.

## Ordering

Events are listed with the most recently created first. There is no sorting, filtering or archiving — this is a tool for a handful of events, not a hundred.

## Deleting an event

There is no delete button. Events are permanent once created, which means an invitation link you have already sent can never break because someone tidied up.

If an event is no longer wanted, remove its guests — that invalidates their links immediately — and leave the event itself alone.
