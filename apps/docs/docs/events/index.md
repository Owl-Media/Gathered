# Managing an Event

Open any event from your [dashboard](/getting-started/dashboard) to reach its management page. Everything about the event is reachable from here.

> 📷 **Screenshot needed:** *Event management header and tabs* (`/images/events/event-header.png`)

## The header

Above the tabs, every section of an event shows the same header:

- **← Back to your events**, returning to the dashboard.
- The **event name**.
- The **date** and **venue name**.
- **Replies close** — or **Replies closed**, in red, once the deadline has passed — with the exact date and time in the event's timezone.
- A **View public page** button, opening the [public event page](/invitations/public-event-page) in a new tab.

## The six sections

| Section | What it covers |
| --- | --- |
| [Details](/events/details) | The event form, and the public event link |
| [Images](/events/images) | Header banner and round profile image |
| [Menu](/events/menu) | Courses and options guests choose from |
| [Guests](/events/guests) | The guest list, private links, invitations and payments |
| [Responses](/events/responses) | Replies, dietary notes, messages and manual edits |
| [Exports](/events/exports) | Planning PDF, CSV and the keepsake messages PDF |

Each section is a real page with its own address, so you can bookmark one, refresh it, or open two in separate tabs. On a phone the tab strip scrolls sideways rather than wrapping, and the content beneath stacks vertically.

## Who can open this page

Only you. Ownership is checked on the server for every section and every action, and an event belonging to someone else returns exactly the same "not found" response as an event that does not exist — so the address bar cannot be used to discover whether an event exists.

If your account has been [disabled](/account/index#disabled-accounts), you cannot reach these pages at all, and your event's public and invitation pages show *"This event is currently unavailable."* to anyone who opens them. No data is deleted.
