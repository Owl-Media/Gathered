# The Public Event Page

Every event has one public page, at an address like `/e/amelias-baby-shower-k7m2p9qx`. Copy it from the top of the [Details](/events/details#public-event-page) tab.

![The public event page: a pastel illustrated header, the date, time and venue, the description, and the full menu grouped by course with vegetarian and vegan labels. A note at the bottom reads "Been invited? Open the private link you were sent to reply."](/images/invitations/public-event-page.png)

## What it shows

- The **header banner** and round **profile image**, or your chosen artwork theme.
- The **event name**.
- **When** — the date, and the start and end times.
- **Where** — the venue name and full address.
- **Details** — your description, if you wrote one.
- **Cost to attend** — the per-guest amount, the deposit and the balance, if the event asks for [contributions](/contributions/index).
- **On the menu** — every course and option, with dietary labels and descriptions.
- A note at the bottom: *"Been invited? Open the private link you were sent to reply. It's just for you."*
- The **last updated** date, once the event has been edited.

## What it never shows

- Any guest's name
- How many people are coming, or have declined, or have not replied
- Anyone's menu choices
- Anyone's dietary requirements
- Anyone's message
- Any private invitation link
- Anything about who has paid

There is no reply form on this page. It cannot be used to RSVP.

## Sharing it

This link is safe to put anywhere — a family group chat, a printed card, a message to somebody who has not been invited. It reveals the event and nothing about the guest list.

::: warning One thing it does reveal
If your event asks guests for a contribution, the amount appears here. The cost is a property of the event, in the same category as the date and the venue, and it says nothing about any individual — but anyone holding the public link can see what the event costs. If that matters, leave the contribution amounts blank and tell guests the figure another way.
:::

## Search engines

The page instructs search engines not to index it, not to follow links from it, and not to cache it. It is not listed in any sitemap, and Gathered has no public directory of events for a crawler to walk. The random suffix in the address means the link is not guessable either.

That said, an unguessable link that is not indexed is still a link. Treat the public page as public: anybody it reaches can pass it on.

## If the page shows "unavailable"

If the organiser's account has been [disabled](/account/index#disabled-accounts), the page shows:

> This event is currently unavailable.

Nothing else is revealed — not why, not by whom, and not whether the event ever existed. No data is deleted, and re-enabling the account restores the page exactly as it was.
