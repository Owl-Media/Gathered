# Invitations

Gathered gives every event two kinds of link, and they behave very differently.

| | [Public event page](/invitations/public-event-page) | [Private guest link](/invitations/private-links) |
| --- | --- | --- |
| Address | `/e/<slug>` | `/rsvp/<token>` |
| How many | One per event | One per guest |
| Safe to share widely | Yes | **No** |
| Shows event details | Yes | Yes |
| Shows the menu | Yes | Yes |
| Shows the cost to attend | Yes | Yes |
| Lets someone reply | No | Yes, after email confirmation |
| Shows any guest's name | No | Only that guest's own |

The public page is a poster. The private link is a personal invitation with the guest's name on it.

## Neither link is indexed

Both the public event page and every invitation page carry `noindex` instructions for search engines, and neither appears in any sitemap or directory. Gathered has no browsable list of events at all — the only way to reach an event is with a link somebody gave you.
